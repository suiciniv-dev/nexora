Issues do GitHub e um quadro mais rápido de usar.

**Issues como no GitHub**

- Página nova de Issues: o quadro do GitHub Projects dos seus repositórios, com as mesmas visões, agrupado por status, com responsável, etiquetas, prioridade, tamanho, PRs vinculados e iteração. Por padrão, só as atribuídas a você.
- Clique numa issue para ler tudo num popup, trocar o status e começar uma sessão com ela: num worktree novo a partir da branch base do projeto (dev, main...), que fica salva, ou na pasta principal.
- Duas contas do GitHub juntas, como a da empresa e a pessoal: cada repositório usa a conta que tem acesso, sem trocar a principal.
- O estado do PR (checks, revisão, rascunho) aparece no cartão de cada sessão do quadro.
- A apresentação ganhou um passo opcional para instalar o GitHub CLI e entrar nas contas.

**Quadro**

- Clicar num cartão abre a conversa numa janela rápida por cima do quadro. Espaço abre, as setas passam de um cartão para o outro e Esc fecha.
- "Por projeto" divide o quadro em uma faixa por projeto, com filtro no cabeçalho.
- Os botões de minimizar, maximizar e fechar voltaram para o canto da janela.

**Uso do plano**

- Página nova de Uso: quanto da sessão e da semana você já usou, lido do próprio `/usage` sem gastar tokens, e a parte de cada projeto por semana.

**Arquivos**

- `Nexora-Setup-0.2.6.exe`: instalador para Windows 10 e 11 (x64). Instala só no seu usuário, sem pedir administrador.
- `Nexora-Portatil-0.2.6.zip`: para PCs com antivírus que barra programas instalados. Extraia e rode o `instalar.cmd` (precisa do .NET 10).

Os arquivos não têm assinatura, então o Windows pode avisar. Clique em **Mais informações** e depois em **Executar assim mesmo**.
