A primeira abertura agora configura tudo, em tela cheia:

- confere o Claude Code, o Git e o Node.js e instala o que faltar com um clique, ou mostra o passo a passo;
- percebe sozinha quando você termina o login do Claude Code;
- traz os workspaces e as pastas com git que você já abriu no VS Code, no Cursor ou no Windsurf.

Também tem o quadro de sessões (quem precisa de você aparece primeiro), projetos e worktrees, e um MCP para todas as sessões do mesmo projeto.

**Arquivos**

- `Nexora-Setup-0.2.2.exe`: instalador para Windows 10 e 11 (x64). Instala só no seu usuário, sem pedir administrador.
- `Nexora-Portatil-0.2.2.zip`: para PCs com antivírus que barra programas instalados. Extraia e rode o `instalar.cmd` (precisa do .NET 10).

Os arquivos não têm assinatura, então o Windows pode avisar. Clique em **Mais informações** e depois em **Executar assim mesmo**.
