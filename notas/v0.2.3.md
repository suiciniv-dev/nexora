Mais leve parado:

- com o Nexora aberto e nada acontecendo, o uso de CPU caiu de cerca de 17% de um núcleo para menos de 3%, e para quase zero quando a janela não está em foco;
- os MCPs do projeto não sobem mais só porque uma sessão abriu: ficam parados até alguém usar. Com 3 sessões paradas num projeto com MCPs, o total caiu de 2,5 GB para 1,3 GB.

**Arquivos**

- `Nexora-Setup-0.2.3.exe`: instalador para Windows 10 e 11 (x64). Instala só no seu usuário, sem pedir administrador.
- `Nexora-Portatil-0.2.3.zip`: para PCs com antivírus que barra programas instalados. Extraia e rode o `instalar.cmd` (precisa do .NET 10).

Os arquivos não têm assinatura, então o Windows pode avisar. Clique em **Mais informações** e depois em **Executar assim mesmo**.
