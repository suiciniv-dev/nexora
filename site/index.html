O problema

Quatro agentes rodando. Qual deles está esperando você?

Agentes de código trabalham muito bem em paralelo. O difícil é acompanhar todos ao mesmo tempo.

  • TrabalhandoRefatorando o serviço de pagamentoClaude Code · terminal 1
  • ProntaEsperando a próxima instruçãoCodex · terminal 2
  • Pede permissãoQuer rodar dotnet ef database updateClaude Code · terminal 3
  • TrabalhandoCorrigindo a tela de pedidos em outra branchGemini CLI · terminal 4

Sem o Nexora

Cada agente fica no seu terminal ou na sua janela. Você só descobre que um terminou, ou parou para pedir permissão, abrindo um por um. E uma aprovação sem resposta trava a tarefa inteira sem avisar.

Com o Nexora

Todas as sessões caem num quadro ao vivo, ordenadas pelo que precisa de você. Permita, negue ou responda no próprio cartão, receba uma notificação quando uma sessão estiver esperando e só entre na conversa quando precisar.

Por que "ADE"? Uma IDE é construída em volta do editor. Um Agent Development Environment é construído em volta dos agentes: das sessões, das aprovações, das branches e das ferramentas deles. O Nexora não substitui o seu agente; é onde você o roda e o acompanha.

Como funciona

Três passos, sem conta nova

  1. 1

    Conecte seus agentes

    O Nexora encontra os agentes de código instalados no seu computador. Cada um entra com a própria conta e o próprio plano, igual faz no terminal.

  2. 2

    Acompanhe todas as sessões

    Cada conversa vira um cartão: precisa de você, trabalhando, pronta ou parada. O cartão mostra o projeto, a branch, o pull request e o que mudou.

  3. 3

    Assuma quando precisar

    Permita, negue ou responda ao agente pelo cartão ou pela conversa. Os pedidos de subagents mostram qual subagent pediu.

O que muda

Veja todos os agentes. Responda de um lugar só.

Quadro ao vivo e aprovações

Cada sessão é um cartão que anda entre precisa de você, trabalhando, pronta e parada. Quando um agente pede permissão, o pedido sobe para o topo do quadro. Aprove ali mesmo e o agente continua, sem abrir a janela dele.

  • Aprovações de todas as sessões reunidas num lugar só
  • Quando o mesmo pedido se repete, responda uma vez para todas
  • Notificação no sistema quando uma sessão está esperando

Orquestração de agentes

Entregue uma tarefa grande a um agente orquestrador. Ele abre outros agentes pelas ferramentas MCP do próprio Nexora, pode colocar cada um na sua branch e no seu worktree, espera por eles e responde às aprovações. Você acompanha tudo num canvas e pode entrar a qualquer momento.

  • Os agentes que ele cria são sessões normais no seu quadro
  • Cada um pode usar um modelo e um esforço diferentes
  • As ferramentas MCP dele são cobertas por testes de ponta a ponta

Worktrees para trabalhar em paralelo

Cada tarefa nova ganha a sua branch e o seu worktree a partir da base do projeto, para os agentes trabalharem em paralelo sem pisar um no outro. Os arquivos de configuração locais vão junto e cada worktree ganha a sua porta.

Hub de MCPs

Os servidores MCP do .mcp.json do projeto sobem uma vez e atendem todas as sessões, em vez de uma cópia por conversa. Sobem no primeiro uso e desligam quando ficam ociosos.

MCPs de 3 sessões no mesmo projeto: 1,3 GB no VS Code, 242 MB no Nexora.Medido no Windows 11 em 04/11/2026.

Funciona com os seus agentes

Claude Code e Codex pelos protocolos nativos, e mais nove agentes pelo Agent Client Protocol (ACP). Cada conversa escolhe o seu.

Código aberto

Licença MIT. O app inteiro está no GitHub: leia, compile você mesmo, abra issues ou contribua.

O que o Nexora nunca toca

O login dos seus agentes. Cada agente entra sozinho, e o Nexora só confere que o login existe, sem lê-lo. Você não paga nada além do plano do seu agente.

O que o Nexora guarda

Só o que você escolhe entregar a ele: segredos que um agente pede pelo formulário protegido, chaves de API de provedores de nuvem e, para as máquinas na nuvem, um claude setup-token. Tudo fica criptografado no DPAPI do Windows ou no Keychain do macOS, no seu computador, e nunca passa pelo chat.

Seu código fica com você

O Nexora não tem IA própria, não envia seu código e não coleta telemetria. Um teste no código reprova qualquer biblioteca de análise, leitura do login dos agentes ou endereço novo na internet. Ele só acessa a internet para buscar atualizações, falar com o GitHub e com as máquinas na nuvem que você conectar. As notícias do Dashboard e o resumo semanal de desempenho são opcionais e vêm desligados. Veja tudo o que sai do seu PC.

Ainda sem assinatura digital

O SmartScreen do Windows e o macOS mostram um aviso na primeira abertura. São dois cliques para abrir: veja no Windows ou no Mac.

Perguntas

Perguntas frequentes

O que o Nexora faz, exatamente?

É um app de desktop para trabalhar com várias sessões de agentes de código ao mesmo tempo. As conversas ficam num quadro ao vivo que mostra quais precisam de você, e dá para responder aprovações, revisar mudanças, cuidar de branches e worktrees, trazer issues do GitHub e entregar tarefas grandes a um orquestrador, sem trocar de janela.

O que é um Agent Development Environment (ADE)?

Uma IDE é organizada em volta de arquivos e de um editor. Um ADE é organizado em volta dos agentes: das sessões, das aprovações que eles precisam, das branches em que trabalham e das ferramentas que compartilham. O Nexora ainda tem editor, diff e terminal, mas os agentes vêm primeiro.

Quem roda os comandos: o Nexora ou o agente?

O agente que você já usa, como o Claude Code ou o Codex. É ele que lê o código, edita arquivos e roda builds e testes, na sua conta e no seu plano. O Nexora não tem IA própria: ele organiza as sessões e passa a você os pedidos de permissão do agente, conforme o modo escolhido. O Nexora só roda o que você pede, como criar um worktree ou iniciar o projeto com o Executar.

É grátis mesmo? É de código aberto?

Sim para as duas. O Nexora é grátis e tem licença MIT, com o código no GitHub. Você só paga o plano do seu agente, como já faz hoje.

Quais agentes funcionam, e quão bem?

Claude Code e Codex têm integração nativa e a maioria dos recursos. Antigravity, GitHub Copilot, Cursor, OpenCode, Kiro, Qwen Code, Grok, goose e Gemini CLI funcionam pelo Agent Client Protocol e estão em beta: os recursos dependem do que cada agente informa. A tabela de compatibilidade tem os detalhes.

Meu código sai do meu computador?

Não pelo Nexora, a não ser que você ligue as máquinas na nuvem para um projeto, e elas vêm desligadas. O agente conversa com o próprio provedor, como faz no terminal. O Nexora só acessa a internet para buscar atualizações, falar com o GitHub e com as máquinas na nuvem que você conectar, e não coleta dados de uso. Um resumo semanal de desempenho, opcional e desligado por padrão, envia só números de recursos, como memória e CPU.

O Nexora vê minha senha ou meu token?

O login dos seus agentes, não: cada agente entra sozinho, e o Nexora só confere que o login existe. O Nexora guarda só credenciais que você mesmo cola nele: um segredo que um agente pede pelo formulário protegido, a chave de API de um provedor de nuvem e, se você usar máquinas na nuvem, o token do claude setup-token. Tudo fica criptografado no cofre do sistema, no seu computador.

O Windows diz "O Windows protegeu o computador". É seguro?

O aviso aparece porque o instalador ainda não tem assinatura digital, e o SmartScreen desconfia de programas que ainda não conhece. Clique em Mais informações e depois em Executar assim mesmo. Se o navegador bloquear o download, abra a lista de downloads, escolha Manter e confirme. O código é aberto, se você preferir compilar.

O Mac diz que a Apple não conseguiu verificar o Nexora. Como abro?

O app ainda não tem a assinatura paga da Apple. Arraste o Nexora para Aplicativos e tente abrir uma vez; feche a mensagem sem mandar para o Lixo. Depois vá em Ajustes do Sistema › Privacidade e Segurança, clique em Abrir Mesmo Assim ao lado da mensagem do Nexora e confirme. No macOS 12 a 14 também dá para clicar com o Control no Nexora, escolher Abrir e confirmar.

Meu antivírus bloqueou. E agora?

Use a versão portátil: ela roda no .NET instalado no Windows, que os antivírus corporativos costumam liberar.

O app está em português?

Sim. O app está em português do Brasil e em inglês e segue o idioma do sistema. Dá para trocar nas Configurações. O agente responde no idioma em que você escrever.

Como atualizo?

Quando sai uma versão nova, aparece um botão Atualizar no topo da janela. Um clique baixa, fecha o Nexora, instala e abre de novo.
